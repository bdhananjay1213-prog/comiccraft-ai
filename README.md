# ComicCraft AI 🎨🤖

ComicCraft AI is an automated AI-powered comic story creator built using FastAPI and Google Gemini models. It allows users to generate multi-panel comic stories, complete with narratives and visuals, directly from creative prompts.

## Features
- **AI Story Generation:** Leverages advanced Gemini models to write compelling comic narratives and panel descriptions.
- **Dynamic Template Rendering:** Powered by FastAPI and Jinja2 for a seamless user interface.
- **Asset Integration:** Automatically handles image processing and layout structuring.

## Tech Stack
- **Backend:** FastAPI, Uvicorn, Python
- **AI SDK:** Google GenAI SDK (`google-genai`)
- **Templating:** Jinja2
- **Utilities:** Pillow, Requests, Python-Dotenv, FPDF
